📋 Socket Events Reference

Event Name Direction Payload
JOIN_CHAT Client → Server { chatId: string }
LEAVE_CHAT Client → Server { chatId: string }
TYPING_START Client → Server { chatId: string }
TYPING_STOP Client → Server { chatId: string }
DELIVERED_ACK Client → Server { messageId: string }
READ_ACK Client → Server { messageId: string }
USER_ONLINE Server → Room { userId, chatId, lastActive }
USER_OFFLINE Server → Room { userId, chatId, lastActive }
MESSAGE_SENT Server → Room { message: IMessage }
MESSAGE_DELIVERED Server → Room { messageId, chatId, userId }
MESSAGE_READ Server → Room { messageId, chatId, userId }
ACK_ERROR Server → Client { message, chatId?, messageId? }
